真实工作流 · 不修改业务代码

七段实录，覆盖那些最容易踩坑的场景。

跨 JetBrains IDE、VS Code 与 Cursor；只有点击播放时才加载视频。

01 · JetBrains

完整 Java POST

捕获 HTTP/2、脱敏 Header 与多层嵌套 JSON Body。

02 · VS Code

Debug 自动捕获

照常启动 Node.js Debug，无需额外执行 CLI 命令。

03 · 离线

JSON 生成 cURL

请求尚未发送，也能离线生成可复现的 cURL。

04 · Safe mode

绕过敏感目标

让 mTLS、证书固定、域名、IP 与 CIDR 目标保持端到端直连。

05 · GoLand

自定义 HTTP Client

对比 Proxy:nil 与显式读取本次进程代理后的捕获结果。

06 · PyCharm

非标准与标准配置

Compound 不暴露环境变量，标准 Python 配置可以安全注入。

07 · Cursor

必须重新 Debug

已运行进程保持不变；重新启动的 Debug 进程才会被捕获。

能适应真实的基础设施。

Safe 模式会让不兼容目标保持端到端 TLS。可以绕过 mTLS、证书固定、 内部基础设施、域名、IP 或 CIDR，同时继续捕获会话中的其他请求。 

# 让基础设施保持直连
autocurl run --all \
  --bypass 10.0.0.0/8 \
  -- go run .
