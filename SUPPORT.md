For a reproducible bug, open a
[GitHub issue](https://github.com/Lingbo-Huang/autocurl/issues/new/choose) and
include the `autocurl doctor` report, IDE/plugin/engine/runtime versions, Run
Configuration type, diagnostic code, and a public minimal reproduction.

Never attach real credentials, cookies, internal hostnames, customer data, or
an unreviewed `--show-secrets` cURL.
